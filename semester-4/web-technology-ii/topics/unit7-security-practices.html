Unit 7: Security in Web Development

Implement practical web security controls against SQL injection, XSS, CSRF, and session threats while strengthening auth, authorization, and secure data handling.

Learning Focus

Recognize attack vectors and map each to preventive controls.
Apply authentication, authorization, and secure session patterns.
Use hashing, HTTPS, and secure coding baseline in Flask apps.
