Unit 6: Web Services and APIs

Design and consume APIs with SOAP/REST understanding, endpoint architecture, HTTP methods, and JSON/XML payload discipline.

Learning Focus

Model resource-oriented API endpoints with clear contracts.
Apply HTTP method semantics for predictable CRUD behavior.
Validate and exchange JSON/XML payloads safely.
