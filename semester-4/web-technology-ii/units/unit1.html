Introduction to Server-Side Development (4 hours)

Unit objectives

This unit introduces the shift from client-side thinking to server-side execution. Students learn how a browser request is processed, how the server responds, and why backend systems must be designed for reliability, scalability, and security.

Learning outcomes

  • Explain client-side and server-side responsibilities in a web application.
  • Describe the HTTP request-response cycle with real browser examples.
  • Identify the role of web clients, application servers, and reverse proxies.
  • Compare monolithic and micro-service architectures at a basic level.
  • Map a simple backend application to the MVC pattern.

Coverage checklist

  • Client-side vs server-side responsibilities
  • HTTP request and response lifecycle
  • Web clients, web servers, and reverse proxies
  • Monolithic vs micro-services architecture
  • Backend language comparison and MVC concept

Classroom focus

Use a simple login or product page example to show how the browser sends a request, how the server looks up data, and how the response changes based on headers, cookies, or form input. This gives students a concrete mental model before they start Python and Flask work.
