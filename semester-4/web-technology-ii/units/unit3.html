Unit objectives

This unit introduces Flask as the framework used to turn Python code into a real web application. Students learn routing, templates, forms, validation, sessions, file uploads, and basic email workflows.

Learning outcomes

  • Set up a Flask project with templates and static files.
  • Create routes and view functions for dynamic pages.
  • Build and validate forms using request handling and flash messages.
  • Explain cookies, sessions, redirects, and secure file upload flow.
  • Understand the pattern for sending email from a Flask application.

Coverage checklist

  • Flask setup and application structure
  • Routing, views, templates, request/response flow
  • Form processing with validation and flashing messages
  • Cookies, sessions, redirects, file uploads
  • Email integration patterns in Flask apps

Classroom focus

Students should leave this unit able to build a small multi-page application, not just a single route demo. A student portal or simple blog is a good practice project because it naturally uses templates, forms, sessions, and uploads.
