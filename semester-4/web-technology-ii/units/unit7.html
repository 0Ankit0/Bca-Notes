Unit objectives

This unit focuses on the security layer of web applications. It covers the major threats students will meet in practice, along with the coding habits and deployment controls that reduce risk.

Learning outcomes

  • Differentiate threats, vulnerabilities, and attacks.
  • Apply least privilege and defense in depth in application design.
  • Recognize SQL injection, XSS, CSRF, and denial-of-service patterns.
  • Use secure authentication, authorization, and session handling practices.
  • Apply secure coding, logging, and deployment protections.

Coverage checklist

  • Security fundamentals: threats, vulnerabilities, attacks
  • Core principles: least privilege, defense in depth
  • SQL injection, XSS, CSRF, DoS attack patterns
  • Authentication, authorization, session hardening
  • Secure coding, logging, and deployment protections

Classroom focus

Students should leave this unit able to explain why a form, login system, or upload feature is vulnerable if validation, encoding, and authorization are skipped. The unit should feel practical, not abstract.
