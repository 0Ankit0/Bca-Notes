Database Integration (8 hours)

Unit objectives

This unit connects Flask applications to databases. Students move from static forms to persistent data using relational modeling, SQL basics, SQLAlchemy, CRUD operations, and transaction handling.

Learning outcomes

  • Differentiate relational and NoSQL database use cases.
  • Set up Flask database access using SQLAlchemy.
  • Design models and tables for a simple application domain.
  • Implement create, read, update, and delete operations through the web interface.
  • Handle transactions and connection errors safely.

Coverage checklist

  • Relational vs NoSQL overview
  • Flask database setup with SQLAlchemy
  • Designing students table and model classes
  • CRUD operations through forms and templates
  • Transaction handling and connection management

Classroom focus

Use a single domain such as student records, book inventory, or employee tracking throughout the unit. Reusing the same data model helps students see how model classes, forms, and SQL statements work together.
