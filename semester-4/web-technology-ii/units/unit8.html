Unit objectives

This unit prepares students to deploy a Flask application in a production setting. It covers environment management, WSGI serving, reverse proxies, HTTPS, and operational monitoring basics.

Learning outcomes

  • Distinguish development and production environments.
  • Use environment variables for safe configuration management.
  • Describe how Gunicorn and a reverse proxy fit into deployment.
  • Explain the role of HTTPS certificates in production security.
  • Recognize logs, monitoring, and rollback as deployment essentials.

Coverage checklist

  • Development vs production environments
  • Environment variables and configuration management
  • Serving Flask with Gunicorn
  • HTTPS setup with Let's Encrypt
  • Monitoring, logs, and security in deployment

Classroom focus

Teach deployment as a repeatable checklist: prepare the app, configure secrets, serve it with a production WSGI server, place it behind a proxy, and verify the site over HTTPS.
