
### CMP 380 Web Technologies I

- Institution: Pokhara University, Faculty of Science and Technology
- Course Title: Web Technology I (3-0-3) Pass Marks: 45
- Nature of the Course: Theory/Practical Total Lectures: 48 hours
- Level: Bachelor | Year: II / Semester: III Program: Bachelor of Computer Application

#### Course Description

This course is designed to make solid foundation in web development. Students start by exploring the evolution of the web and understanding key concepts like client-server architecture and web protocols. The course covers HTML, CSS, JavaScript and advanced features to make web pages interactive including version control, UI/UX, wireframing, and SEO.

#### General Objectives

The general objectives of this course are as follows:

- To provide how to create web pages using HTML, including working with elements, attributes, and various components like lists, links, images, and forms.
- To enable students to style and layout web pages using CSS, covering basics, the CSS box model, responsive design, and advanced layout techniques like Flexbox and Grid.
- To build students' JavaScript skills, including how to write scripts, handle events.
- To provide an overview of JavaScript frameworks and libraries, including jQuery, React and introduce popular frameworks like Angular, and Vue.js.
- To offer a foundation in web design principles, including UI/UX design, wireframing, typography, color theory, usability, accessibility, and SEO.
